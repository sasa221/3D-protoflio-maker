# 3D Portfolio Maker

Turn your CV into a recruiter-ready interactive 3D portfolio — no coding required.

🔗 **Live Demo:** https://portfolio-maker-murex.vercel.app

<p align="center">
  <img src="screenshots/home.png" width="680" alt="3D Portfolio Maker home page">
</p>

## What it does

- Import your CV and auto-fill your portfolio
- Cinematic 3D views with customizable themes
- Multiple portfolio variants for different job targets
- Publish and share — built-in visitor analytics
- Pro/Premium tiers with advanced features

<p align="center">
  Built with Vanilla JavaScript + Vite + Three.js renderer + Supabase.
</p>
